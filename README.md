# Cookies

Exemplo didático de uso de cookies com HTML, CSS e JavaScript.

## Como executar

1. Abra o arquivo `index.html` no navegador, ou
2. Inicie um servidor simples na pasta do projeto com:
   `python -m http.server 3000`
   e acesse `http://localhost:3000/`

## O que o exemplo faz

- Salva um cookie com o nome digitado.
- Lê o cookie salvo.
- Apaga o cookie do navegador.
